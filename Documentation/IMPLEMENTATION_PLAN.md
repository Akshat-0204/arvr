## 1. Goal & scope

**Goal:** Android AR app: scan a table → tap to drop a build area → tap to add/remove blocks of chosen material → rotate/scale the whole build → undo, clear, save/load.

**In:** single build area, 16×16×16 grid, 5 cm blocks, 8 flat-colour materials, build/break modes, undo (50 steps), 3 save slots, rotate/scale build, re-place build area.
**Out (YAGNI for v1):** textures, chunked meshing, multiplayer, cloud anchors, gravity/physics, sound, multiple worlds at once.
**Fail even if it "works":** taps on UI also place blocks; blocks drift off the table; app crashes on missing/corrupt save; build lost on pause/resume.

## 3. Architecture

```
MainScene (1 GameObject: "Bootstrap" + SceneBootstrap)
        │ Awake
        ▼
SceneBootstrap ── builds ──► AR Session, XR Origin (+PlaneManager, RaycastManager, AnchorManager), AR Camera
              ├─ builds ──► [App] AppManager, WorldPlacement, BlockInteractor
              ├─ builds ──► Reticle (runtime quad, M_Overlay)
              └─ builds ──► UI via UIBuilder → UIManager, PaletteBar

WorldPlacement: reticle → tap → spawn WorldRoot at plane pose (ARAnchor) + BasePlate
WorldRoot (ARObjectManipulator: pinch/twist)
   └─ VoxelWorldView ── renders ── VoxelGrid (pure C#)
BlockInteractor: tap → Physics.Raycast → GridMath → EditHistory.Apply(cmd) → VoxelGrid
SaveSystem: VoxelGrid ⇄ JSON (persistentDataPath/builds/slot{n}.json)
```

Pure C# (no `MonoBehaviour`, EditMode-testable): `VoxelGrid`, `GridMath`, `EditHistory`, `VoxelSerializer`, `BlockPalette`.

| Constant | Value |

| Undo depth | 50 |

### Task 2 — `VoxelGrid` + `GridMath` (pure C#)
- **Produces:**
  - `class VoxelGrid { VoxelGrid(Vector3Int size); Vector3Int Size; bool InBounds(Vector3Int c); byte Get(Vector3Int c); bool Set(Vector3Int c, byte id); int Count; IEnumerable<(Vector3Int cell, byte id)> All(); void Clear(); event Action<Vector3Int, byte> CellChanged; event Action Cleared; }`
    - `Set` returns false (no event) if out of bounds or value unchanged. `Set(c, 0)` = remove.
  - `static class GridMath { Vector3Int LocalToCell(Vector3 local, float blockSize); Vector3 CellToLocal(Vector3Int c, float blockSize); Vector3Int TargetCell(Vector3 localHitPoint, Vector3 localNormal, float blockSize, bool build); }`
    - Grid origin: cell (0,0,0) min corner at local `(-size.x/2·bs, 0, -size.z/2·bs)`; y=0 is base-plate top. `CellToLocal` returns cell centre.
    - `TargetCell`: nudge hit point by `±normal·bs·0.5` (+ when build, − when break) then `LocalToCell`. Avoids float-on-face ambiguity.
- **Tests** (`VoxelGridTests`, `GridMathTests`): set/get round trip; out-of-bounds `(16,0,0)` and `(-1,0,0)` → false, Count unchanged; same-value set fires no event; Clear fires `Cleared`, Count 0; `CellToLocal(LocalToCell(p))` within bs/2 of p; hit on top face of cell (3,0,3) with normal up → build target (3,1,3), break target (3,0,3); hit on base plate (y=0, normal up) → build (x,0,z).
- Commit `feat: voxel grid and grid math`.

### Task 5 — `EditHistory` + `BlockInteractor`
- **Produces:**
  - `struct EditCommand { Vector3Int Cell; byte Before; byte After; }`
  - `class EditHistory { EditHistory(VoxelGrid g, int depth = 50); bool Apply(Vector3Int cell, byte id); bool Undo(); bool CanUndo; void Clear(); }` — `Apply` records only if `grid.Set` returned true; oldest dropped past depth. Grid `Clear()` via history also undoable as one step (store snapshot list).
  - `enum ToolMode { Build, Break }`
  - `class BlockInteractor : MonoBehaviour { ToolMode Mode; byte SelectedBlock = 1; }` — active only when `WorldPlacement.IsPlaced`. On tap (rule in §3): `Physics.Raycast` from AR camera through touch, mask `Voxel`; convert hit to WorldRoot local space (`InverseTransformPoint` / `InverseTransformDirection`, divide out scale implicitly since grid is in local units); `GridMath.TargetCell`; `history.Apply(cell, Mode==Build ? SelectedBlock : 0)`. Break on BasePlate = no-op.
  - Two-finger touches never count as tap (reset tap tracking when `touchCount > 1` at any point during the gesture).
- **Tests** (`EditHistoryTests`): apply then undo restores 0; undo on empty → false; 51 applies → only 50 undoable; no-op apply (same value / out of bounds) not recorded; clear-then-undo restores all blocks.
- **Verify (XR Simulation, mouse):** click plate → block; click block side → neighbour; Break removes; clicks on UI do nothing.

## 5. Review focus (likely to bite, check every task)

1. **Tap over UI edits world** — every touch path must check `EventSystem.IsPointerOverGameObject(fingerId)`.
2. **Pinch start/end registered as tap** — two-finger gesture must cancel pending tap.
3. **Scaled/rotated world** → wrong cell. All hit math in WorldRoot local space; test at scale 0.25 and 3.0.
4. **Pause/resume / tracking lost** → build vanishes or jumps. Grid data independent of anchor; autosave on pause.
5. **Corrupt or missing save file** → crash. Serializer never throws; UI shows toast.
